# Meta / Instagram secrets

Never commit Meta or Instagram tokens to this repository.

Required GitHub Actions secrets:

- `META_IG_ACCESS_TOKEN` — Instagram User access token generated by Meta.
- `META_IG_USER_ID` — Instagram professional account user ID.

Use the manual workflow **Test Instagram API** to verify the connection without exposing the token in logs.

After the connection test passes, the publishing workflow will be added.
